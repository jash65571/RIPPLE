# Marketing kit index

This folder organizes launch-ready copy and asset guidance. Nothing here has been posted or sent. The product name, public URL, policy pages, and owner identity must be approved first.

- `POSITIONING.md`: audience, value, differentiator, and verified scope
- `SITE_COPY.md`: the copy used on the current landing page
- `PRESS_SHEET.md`: short press facts, features, controls, platforms, and status
- `POSTS_AND_OUTREACH.md`: draft social copy and five outreach categories
- `LAUNCH_PLAN.md`: four-week zero-spend plan with stop and go checks
- `ASSET_INDEX.md`: real-game screenshots, promos, and trailer sources

The larger working copy bank remains in `docs/MARKETING.md`.
