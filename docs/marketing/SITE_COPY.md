# Landing page copy

## Main line

Watch the delay. Change the plan.

## Introduction

A calm cause-and-effect puzzle set in a tiny harbor. Rewind the morning, change one rule, and test whether your plan still works when the day changes.

## Three steps

1. Watch vehicles share narrow harbor routes and see where the delay begins.
2. Change only the route or departure choice allowed by the puzzle.
3. Test one plan against every possible version of the day.

## Verified features

Ten levels with an ending, local progress, offline play after download, keyboard and touch controls, text play, adjustable motion and text, optional sound, no login, and no ads.
