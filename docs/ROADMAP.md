# Short roadmap

The current release is a complete ten-level chapter. New work starts only after launch feedback supports it.

## Possible next chapter

- New deterministic fixtures using the existing versioned level format
- More combinations of closures, linked starts, and visible shared resources
- Additional original harbor scenery that does not change the tested simulation rules

## Separate product decisions

Accounts, cloud saves, payments, native wrappers, analytics, user-made levels, and multiplayer are not assumed. Each would need its own privacy, security, cost, accessibility, and release review before implementation.
