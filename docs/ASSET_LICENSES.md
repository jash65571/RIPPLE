# Asset and license register

## First-party work

- Harbor scenes, vehicle forms, water, roads, buildings, trees, UI styling, icon pixels, and marketing captures are original project work generated from code in this repository.
- Sound effects and the optional harbor tone are generated at runtime with Web Audio oscillators. They use no samples.
- Screenshots and WebM captures show the running game. No AI-generated SVG artwork or third-party image asset is included.

## Runtime software

- PixiJS 8.20.1, MIT license
- React and React DOM 19.3.0, MIT license
- Workbox runtime included by vite-plugin-pwa, MIT license

The release packager copies license notices from installed packages into `THIRD_PARTY_NOTICES.txt` in each archive. Build and test tooling is not shipped as application runtime code.

## Reuse policy

Do not add an image, font, sound, or code sample until its source, author, license, required attribution, and allowed commercial use are recorded here. A search result or download availability is not a license.
