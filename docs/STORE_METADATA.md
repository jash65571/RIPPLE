# Store metadata draft

## Identity

- Working title: RIPPLE
- Version: 1.0.0
- Product ID: com.jash.ripple
- Category: Puzzle, with Casual as a secondary category where available
- Price: Free
- Accounts: None
- Ads and purchases: None
- Network: Not required after the web app is installed and cached

## Age-rating draft

No violence, fear, gambling, substances, sexual content, user communication, location use, or unrestricted web access is designed into the game. The owner must complete each storefront questionnaire because the platform, not this draft, assigns the rating.

## Privacy-label draft

The current build collects no player data through application code and does not include analytics or advertising SDKs. Static hosting may process ordinary request and security logs. Recheck the deployed host, wrapper SDKs, crash reporting, and support channel before answering any store privacy form.

## Required owner fields

Final name, subtitle, publisher name, copyright holder, support URL, privacy URL, marketing URL, public production URL, screenshots, app preview choice, content rights declaration, encryption answers, regional availability, and reviewer contact.
