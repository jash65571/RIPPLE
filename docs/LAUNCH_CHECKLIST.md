# Launch checklist

## Required before public launch

- [x] Ten deterministic levels validate and have one intended solution each.
- [x] Full campaign can be completed through visible controls.
- [x] Desktop and phone screenshot runs cover every level.
- [x] Undo, redo, reset recovery, reveal recovery, and original comparison exist.
- [x] Multi-future tests evaluate every possible day.
- [x] IndexedDB save, import, export, migration, and stale-tab protection exist.
- [x] PWA install metadata, offline cache, and safe update prompt exist.
- [x] Keyboard controls, focus styles, text mode, reduced motion, and text scaling exist.
- [x] Original coded artwork, procedural sound, public pages, promo captures, and release archives exist.
- [x] First-party content gate rejects em dashes, en dashes, and SVG artwork.
- [ ] Owner supplies publisher identity, production URL, and support contact.
- [ ] Owner approves privacy and terms drafts with qualified legal review if needed.
- [ ] Owner chooses a final product name after trademark clearance.
- [ ] Physical iOS and Android device acceptance passes.
- [ ] Firefox and WebKit automation runs on a machine where Playwright browsers can be installed.
- [ ] Public URLs, headers, social cards, and service-worker update behavior are checked on the chosen host.
- [ ] Store accounts, age ratings, privacy labels, listing fields, and screenshots are completed by the owner.

Do not publish while any unchecked owner or platform item remains.
