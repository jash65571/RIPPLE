Accessibility

Every plan action uses an HTML button. The ten puzzles can be completed with a keyboard. Focus rings remain visible, important status never depends on color alone, and each board has a structured text play view using the same simulation.

Controls and display

  • Tab moves between major controls.
  • Enter or Space activates the focused button.
  • Previous event and Next event provide an alternative to scrubbing.
  • Reduced motion removes automatic playback and celebration movement.
  • Text size can be increased from Settings.
  • Effects and music can be controlled separately.

Current verification

Automated keyboard and browser checks passed in system Chrome at phone and desktop sizes. Firefox, WebKit, real assistive technology, and physical devices still need separate acceptance. Contact information must be configured before public release.

Private review draft. Do not treat automated checks alone as a claim of complete screen-reader support.
