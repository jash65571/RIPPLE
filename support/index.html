Support

A real support email or issue link must be configured before public release. This review build sends nothing automatically.

Back up progress

Open Settings in the game and choose Export progress. Keep the JSON file somewhere you control. To restore it, choose Import progress and review the summary before replacing the current save.

Offline play

Open the complete game online once and wait for the Offline ready notice. If content is missing, reconnect and reload. Browser storage and installed-app storage may differ by platform.

Useful bug details

Include the level number, content version, selected route or start beat, possible day, browser name, and what you expected. Do not include passwords, access tokens, private files, or unrelated browsing data.
